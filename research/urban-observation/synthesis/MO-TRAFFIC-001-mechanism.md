# Mechanism Map — MO-TRAFFIC-001

## Observed scene

- **[Observed]** 澳门街头存在没有交通灯的人行横道；在观察范围内，行人准备过街时，多数接近车辆减速或停车让行。
- **[Observed]** 观察者没有注意到明显可见的红绿灯或交通摄像头。
- **[Uncertain]** 观察卡没有记录具体道路、时段、车辆和行人数量、道路几何、车辆类型或连续行为过程，因此“多数”不能转换为让行率。

## Hypothesis update

- **H1 — 明确的让行规则与责任预期：Medium-High。** 第37条明确覆盖不是由交通灯或执法人员指挥的人行横道，第103条规定不让行的罚则，官方交通安全宣传也重复传递该规则（E025、E026、E029）。但2025年仍记录619宗斑马线不让先处罚（E033），所以规则支持的是行为预期，不是普遍合规。
- **H2 — 道路几何与低速环境：Medium。** 官方手册和道路优化个案显示，标线、预告标记、安全岛、导流设施及减速设计可以降低识别和停车难度（E027、E028）；跨地区研究也支持速度、车距和现场情境影响无信号过街让行（E035、E036）。但观察点的道路宽度、限速和设施没有记录。
- **H3 — 即时互动与社会规范：Low-Medium。** 现场行为与无信号过街的互动模型相容，但没有直接记录眼神、手势、试探性迈步、后车反应或司机访谈，因此只能保留为次级机制（E024、E035）。
- **H4 — 职业司机和车队组织：Low；不作为主要解释。** 当前材料没有按出租车、公交、旅游巴士和私家车区分让行行为，也没有澳门本地车队培训、投诉或保险数据，不能把秩序归因于职业驾驶者。
- **H5 — 不可见的监督与事故追责：Medium。** 澳门存在公共空间视频监视、交通控制中心和历史上的联合巡查执法资料（E030—E032），但没有证据证明观察点有专用摄像头，或摄像头会自动处罚不让行（E031、E032）。

## Immediate constraint

**[Inferred]** 无交通灯的人行横道把过街优先权的识别和时机判断交给道路标线、行人意图、车辆速度与双方即时协调。车辆既不能依靠信号灯获得明确放行，也不能忽略斑马线带来的法定让行要求；在狭窄、低速或视线较好的道路上，减速和短暂停车的成本可能较低。具体观察点是否具备这些条件，仍待补录。

## Rule / institution

- **[Verified]** 澳门《道路交通法》第37条规定，接近有适当信号标明、但不是由交通灯或执法人员指挥的人行横道时，驾驶员应减速或在必要时停车，让正在横过车行道的行人通过（E025）。
- **[Verified]** 第103条把违反第37条的不让行人先行列为违法，并设有罚金和累犯的更高责任（E026）。
- **[Verified]** 交通信号及道路标志标线手册把斑马线、行人标志、注意行人标志和减速预告标记作为传递道路信息的设施（E027）。
- **[Inferred]** 因此，现场秩序的制度基础不是单一红绿灯，而是法律优先权、道路信息设施和交通部门的设置维护共同构成的规则环境。

## Incentive effect

- **[Inferred]** 对驾驶员而言，减速或停车有时间和通行成本；不让行则可能产生罚金、事故责任、车辆损坏和后续纠纷成本。即使发现概率不高，法定责任也会提高不让行的预期成本。
- **[Verified]** 2025年仍有斑马线不让先处罚记录（E033），说明制度激励并未把所有司机转化为稳定合规者；观察到的让行与总体存在违规可以同时成立。
- **[Inferred]** 纵向减速标线和人行横道预告标记通过提前提醒和视觉收窄降低判断不确定性，可能使“先减速再确认”比临近横道时急刹更便宜、更安全（E028）。

## Behavioral response

- **[Observed]** 现场多数接近车辆在行人准备过街时减速或停车。
- **[Verified]** 法律直接要求让正在横过的行人先行；观察到的“行人尚未进入横道即减速”可能是对行人意图的提前判断，但不能仅凭观察卡认定为法定必须停车（E025）。
- **[Inferred]** 行人站在路缘、朝向横道或开始迈步，可能成为司机判断意图的信号；司机减速、停车和停车位置又向行人反馈“可以通过”。这一互动机制在本地尚未被连续视频或访谈直接验证。
- **[Comparative research]** 无信号过街研究表明，车辆速度、车距、行人与车辆到达时机及现场情境会影响让行决策（E035、E036）；这支持道路条件和即时互动的组合解释，而不是单一“文明程度”解释。

## Enforcement / feedback

- **[Verified]** 治安警察局持续发布人行横道让行安全信息，并有历史上的联合宣传、巡查和违规处理行动（E029、E030）。
- **[Verified]** 澳门公开资料显示存在公共空间视频监视和交通控制中心实时路况服务（E031、E032）。
- **[Uncertain]** 这些监控是否覆盖观察点、是否保存过街行为、是否用于自动识别不让行，现有材料无法确认；不能把现场看不到摄像头写成没有监督。
- **[Inferred]** 违法处罚、事故调查、投诉和执法宣传会形成反馈：违规较多或冲突较集中的路段可能获得更多巡查、标线调整或工程改造；当前台账没有事故点位和投诉数据，反馈链条尚未量化。

## Organization / operator

- **[Verified]** 澳门的道路交通法制、交通事务局道路设施、治安警察局执法与公共视频监视制度分别承担规则制定、设施布置、现场执法和监控治理职能（E025—E032）。
- **[Inferred]** 街头让行并非单个司机独立生产的结果，而是公共部门提供规则和设施、司机与行人反复执行、执法与事故责任进行纠偏的组织化结果。
- **[Uncertain]** 观察点附近是否有学校、旅游区、公交站、车队运营或特殊道路管理安排，均未记录；因此不能进一步判断职业司机或特定组织的边际作用。

## Distribution

- **Who gains / 谁受益：**
  - **[Inferred]** 行人获得更低的等待和过街冲突成本，尤其是儿童、老年人和行动较慢者。
  - **[Inferred]** 司机在不必为每个路口等待完整信号周期的情况下保持通行，交通部门也可以用标线、标志和局部工程处理部分过街需求。
- **Who pays / 谁付费：**
  - **[Verified]** 公共部门需要承担道路标线、标志、安全岛、减速设施、监控和执法的建设与维护成本（E027—E032）。
  - **[Inferred]** 司机承担减速的时间成本和违法罚金；行人承担等待、识别来车和确认安全的注意力成本。
- **Who bears risk / 谁承担风险：**
  - **[Inferred]** 一旦司机误判、行人意图不清或道路视线受阻，身体伤害风险主要落在行人，事故责任和财产损失风险则由司机、车主及保险安排分担。
  - **[Uncertain]** 不同车辆类型、不同街区和不同天气下的风险差异尚无现场数据。
- **Who is excluded / 谁被排除：**
  - **[Inferred]** 依赖明确倒计时、声音提示或完全隔离过街的行人，在缺少信号灯的路段承担更多自我判断负担；如果标线磨损、照明不足或车速较高，实际可达性会下降。

## Failure mode and rule removal

- **[Inferred]** 如果删除人行横道标线、让行规则或执法反馈，司机和行人将失去共同的优先权参照，过街协商成本和让行行为的波动可能上升。
- **[Inferred]** 交通信号灯并不是唯一替代方案；在适合的道路上，清晰标线、减速设计、照明和安全岛可能继续维持部分秩序，但其效果依赖车速、视距和交通流量。
- **[Uncertain]** 现有材料无法预测移除某一项设施后让行率会下降多少，也不能判断哪些路段必须改用信号灯；需要同一路段的前后对照或跨点位行为计数。

## Historical path

- **[Verified]** 澳门交通治理至少经历了1993年道路交通规章到2007年综合《道路交通法》的制度演变（E034）。人行横道让行由早期交通规制逐步嵌入现行综合法制，而不是临时形成的单一街头习惯。
- **[Verified]** 后续道路工程继续通过标线、预告标记、安全岛和导流设施调整无信号过街环境；2024年氹仔苏利安圆形地个案明确把车流量、车速和过街安全联系起来（E028）。
- **[Verified]** 交通信号手册和持续的警方宣传把这些规则与设施反复标准化、重复传播（E027、E029）。
- **[Inferred]** 长期重复的法定优先权和道路信息设施可能形成司机与行人的共同预期，使无灯人行横道在部分低速城市路段成为可持续安排。
- **[Uncertain]** 现有资料不能确定澳门无灯人行横道行为规范的起始年份，也不能证明它在所有街区、时段和道路等级上同样有效。

## Competing explanation retained

1. **主解释：规则—工程—监督的叠加机制。** 法定让行义务提供最低行为标准，道路标线和减速设计降低识别与停车成本，巡查、处罚、事故追责和可能存在的远端监控提供反馈；这组机制同时解释“看不到红绿灯仍能让行”和“仍有不让行处罚”两类材料。
2. **次解释：司机与行人的即时协调。** 眼神、站位、迈步、减速和停车可能在每次过街中完成信号交换，但目前没有直接行为记录，不能把它写成已经证实的社会规范。
3. **保留的反解释：现场观察可能高估秩序。** 单次旅行观察、未记录地点和没有样本分母，可能只捕捉到低速、游客较少或更容易让行的路段；E033提醒不能从少量顺利过街推导总体让行率。
4. **不采用为主要解释：职业司机或车队组织。** H4缺少车辆类型和组织制度证据，后续只有在区分出租车、公交、旅游巴士和私家车后才能重新评估。

## Confidence

**Medium**：现有材料足以支持“澳门无灯人行横道的秩序由法定让行规则、道路信息与减速工程、以及部分可见或不可见的执法反馈共同维持”的多重机制；但现场观察没有地点、时段、样本分母和连续行为记录，无法确认实际让行率、即时互动、摄像头覆盖或不同车辆类型的差异。

## One-sentence mechanism

澳门无交通灯人行横道的让行秩序，不是单纯依靠司机自觉，而是由人行横道法定优先权、标线与减速工程降低协调成本、司机与行人的即时判断，以及巡查、处罚、事故追责和可能存在的远端监控共同生产；现场观察支持这一叠加机制，但尚不足以量化其稳定性。
