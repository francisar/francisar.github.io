# Mechanism Map — MO-CURRENCY-001

## Observed scene

- **[Observed]** 观察记录称澳门体量很小，港币广泛使用，但澳门仍保留澳门元（E039）。
- **[Observed]** 原始记录没有说明具体商户、街区、交易金额、价格标示、找零货币、支付方式或观察日期，因此“港币广泛使用”目前仍是未经量化的现场判断。
- **[Verified]** 官方资料显示澳门元仍具有法定货币地位、持续发行和本地价格计价功能；银行体系和支付基础设施则同时容纳澳门元、港元及其他货币（E040—E049）。
- **[Uncertain]** 现有材料不能直接说明澳门居民在工资、消费、储蓄、贷款和投资中分别选择何种货币（E050、E053）。

## Hypothesis update

- **H1 — 本地法定计价与公共管理功能：Medium-High，保留但收窄。** 第10/2023号法律确认澳门元的法定货币和发行制度，第16/95/M号法令把澳门元嵌入价格、工资和电子支付的正式计价层，澳门元纸币也在2024—2026年持续更新发行（E040、E041、E049）。这些证据支持澳门元具有不可由商户接受港币直接替代的制度功能；但公共收费、政府工资和全部法律合同的实际货币分布尚未逐项核验。
- **H2 — 联系汇率与低兑换摩擦：Medium-High，保留。** 货币发行局制度、港元联系汇率、外汇储备覆盖和旅游部门的兑换安排，使澳门元与港元之间的汇率风险较低（E042、E044、E046）。2019年前后的商户调查显示外币接受与汇率透明度并不完全同步，约六成商户清晰标示兑换率，因此“完全无摩擦、完全等值”的强版本被削弱（E043）。
- **H3 — 行业和交易网络分工：Medium，保留为重要机制。** 旅游信息、支付系统和历史货币研究支持港元进入旅游、跨境和部分金融网络，澳门元继续承担本地计价和结算功能（E041、E042、E047、E051）。但目前没有按赌场、酒店、零售、交通、居民社区和公共服务拆分的交易数据，不能把行业分工写成已证实的比例关系。
- **H4 — 历史路径依赖与制度边界：Medium，保留为支撑机制。** 澳门元从1905—1906年发钞安排、1980年发行机构、1989年政府收回发钞权到1995年第二家发钞代理行，制度连续性明显；当前仍持续发行纸币（E048、E049）。历史材料支持机构路径依赖，但没有直接证明居民对澳门元存在身份认同，也不能单独证明政治象征是主要动因。
- **H5 — 居民按场景组合使用货币：Medium-Low，作为待验证假设保留。** 2026年6月银行体系的港元存款、贷款和M2占比较高，2025年居民境外证券投资规模也很大，说明港元可能超出游客现金交易而进入金融和资产配置网络（E045、E050）。但统计口径包含企业、政府、居民及非居民，证券投资调查也没有披露投资币种，因此不能确认普通居民“按港币储蓄、投资和使用”。

没有一个假设被整体否定，但以下强命题应被拒绝：澳门元只是象征性保留；港元与澳门元在所有交易中完全等值且无摩擦；以及港元使用完全由游客、赌场或少数企业造成。相反，“居民普遍只使用澳门元”同样没有证据支持。

## Immediate constraint

**[Inferred]** 澳门同时面对两个约束：一方面，本地政府、工资、价格、支付和金融监管需要一个稳定的本地记账与法偿单位；另一方面，旅游、跨境流动和香港金融联系又持续带来港元需求。澳门不必在“只用澳门元”和“正式港币化”之间二选一，而可以让澳门元承担制度计价，让港元在私人交易、跨境消费和金融网络中承担补充功能。

这个安排的前提是两种货币能够低成本转换。联系汇率和储备覆盖降低了名义汇率风险，但商户仍可能面对报价、找零、汇率披露和现金管理成本；消费者也可能因为信息不足承担隐含价差（E043、E044、E046）。

## Rule / institution

- **[Verified]** 第10/2023号法律确认澳门元为澳门特别行政区法定货币，并将货币发行特权、金融管理局职责和法偿力纳入现行制度（E040）。
- **[Verified]** 第16/95/M号法令把澳门元置于本地价格、工资和销售点电子支付的正式计价层，同时允许在部分商业场景并列使用其他货币（E041）。
- **[Verified]** 澳门采用货币发行局制度，澳门元与港元实行联系汇率，发钞与外汇储备覆盖相互绑定（E044、E046）。
- **[Verified]** 澳门元纸币仍在持续发行和更新，说明本地货币由政府、金融管理机构、发钞代理行和银行支付系统共同维护，而不是只靠历史名称存在（E049）。
- **[Inferred]** 港元在澳门的广泛接受主要通过商户选择、旅游需求、跨境金融网络和支付基础设施实现；它可以补充澳门元的交易功能，但没有因此取代澳门元的法定计价和发行制度。

## Incentive effect

- **[Inferred]** 对政府和金融管理机构而言，保留澳门元可以统一公共价格、工资、税费、预算、合同和金融监管的记账单位，避免把本地行政系统完全改写为港元。
- **[Inferred]** 对旅游、博彩、酒店、零售和跨境服务商户而言，接受港元可以减少游客换汇步骤、扩大可交易客户范围，并利用香港的现金和金融网络；这解释了私人部门为什么会在澳门元计价之外接受港元。
- **[Inferred]** 对居民和企业而言，澳门元适合本地支出和负债，港元则可能适合跨境消费、香港金融产品或资产配置；在联系汇率下，分散持有两种货币的汇率风险较低。
- **[Verified]** 银行体系的M2、存款和贷款均呈现澳门元与港元并存的结构（E045），说明这种激励不只发生在街头现金交易，也存在于金融中介层。
- **[Challenging evidence]** 商户接受外币并不必然意味着交易没有成本。汇率是否清晰标示、找零使用何种货币、商户如何承担价差和现金处理成本，仍会影响实际选择（E043、E053）。

## Behavioral response

- **[Verified]** 官方旅游信息以澳门元作为商品和服务收费单位，同时向旅客说明港元兑换澳门元的方式和渠道（E042）。
- **[Inferred]** 商户可能采用“澳门元报价、港元收款、按店内或当日汇率换算”的组合；这能同时满足本地计价规则和游客支付便利，但具体报价和找零规则必须通过现场记录验证。
- **[Inferred]** 银行和支付系统可能把澳门元、港元及其他货币分置于不同账户、结算和兑换路径中；居民因收入来源、跨境联系、资产期限和支出地点不同而形成货币组合，而不是做一次性“澳门元或港元”的选择。
- **[Uncertain]** 现有观察没有记录价格牌、收银台、找零、ATM、银行卡账单或居民访谈，因此不能把上述行为写成已观察事实，也不能从商户接受港元推断居民以港元储蓄或投资。

## Enforcement / feedback

- **[Verified]** 法定货币、价格计价和电子支付规则为澳门元提供了正式的制度反馈；货币发行局和储备覆盖则通过维持可兑换性与汇率稳定提供金融反馈（E040、E041、E044、E046）。
- **[Verified]** 消费者委员会曾调查商户接受港元和人民币以及兑换率标示情况，说明外币接受和汇率信息透明度是可被公共治理关注的消费问题（E043）。
- **[Inferred]** 监管反馈的重点更可能是货币发行安全、银行结算、汇率和消费者信息，而不是强制所有私人交易只使用澳门元；这使“法定货币”和“实际接受货币”可以并存。
- **[Uncertain]** 目前没有足够材料判断商户采用何种汇率是否普遍受到处罚、消费者是否经常投诉、港币找零是否存在稳定的行业惯例，也没有居民层面的货币选择监督数据。

## Organization / operator

- **[Verified]** 澳门特别行政区政府和澳门金融管理局负责澳门元发行及货币制度接口，发钞代理行、商业银行和支付机构负责纸币、账户、兑换与结算网络（E040、E044、E047、E049）。
- **[Verified]** 旅游部门通过面向旅客的价格和兑换说明降低跨境交易的信息成本，商户、酒店、赌场、交通服务商和银行则把港元需求转化为具体收款和兑换安排（E042）。
- **[Inferred]** 香港金融市场、跨境游客和企业的港元网络，以及澳门本地政府收费、工资、合同和社区消费的澳门元网络，形成两个相互连接但不完全相同的组织体系。
- **[Uncertain]** 现有材料不能识别赌场、银行、公共交通、出租车、街边零售和居民社区之间的货币接受差异，也不能识别不同收入群体的议价能力和货币选择。

## Distribution

- **Who gains / 谁受益：**
  - **[Inferred]** 旅游和跨境商户、游客及经常往返香港的消费者可以减少换汇和支付中断；银行及支付机构获得双货币兑换、结算和账户服务需求。
  - **[Inferred]** 本地政府和金融机构保留统一的澳门元计价和发行接口，不必为私人部门接受港元而放弃本地货币治理能力。
  - **[Uncertain]** 居民是否因澳门元工资和本地支出、港元资产或跨境收入而获得不同收益，尚无家庭层面的分组数据。
- **Who pays / 谁付费：**
  - **[Inferred]** 澳门政府和金融管理机构承担发行、储备管理、监管和支付基础设施维护成本；银行和商户承担兑换、现金管理、汇率披露和系统处理成本。
  - **[Inferred]** 居民和游客承担学习双货币报价、判断汇率、处理找零和比较费用的认知成本；信息较少的消费者可能支付更高的隐含价差。
- **Who bears risk / 谁承担风险：**
  - **[Inferred]** 商户承担收款货币与记账货币之间的短期价差、假钞和找零风险；居民承担资产和负债币种不匹配的风险，尤其是在收入、支出和投资跨越不同货币时。
  - **[Inferred]** 澳门整体通过联系汇率和储备覆盖降低名义汇率风险，但相应地保留了对外部金融条件和港元体系的依赖，货币政策自主空间受到约束。
  - **[Uncertain]** 不同群体的实际风险暴露、银行费用和汇率价差尚未获得可比数据。
- **Who is excluded / 谁被排除：**
  - **[Inferred]** 不熟悉双货币换算、缺少银行服务或无法比较汇率的消费者，更难识别真实价格；只接受单一货币的商户也可能被排除在部分游客和跨境客户之外。
  - **[Uncertain]** 现有资料无法判断这种排除在老年人、低收入家庭、跨境劳动者或小微商户中的程度。

## Failure mode and rule removal

- **[Inferred]** 如果取消澳门元，政府收费、工资、价格、合同、银行账户、贷款、纸币硬币和支付系统都需要进行统一换算；港元可以承接许多私人交易，但制度切换成本和分配影响不会消失。
- **[Inferred]** 如果限制港元在私人交易中的接受，澳门元本地计价系统仍可运行，但旅游、跨境消费、赌场及与香港金融网络相连的商户会增加换汇和结算摩擦。
- **[Inferred]** 如果联系汇率、储备覆盖或兑换便利性显著改变，港元与澳门元的相对持有和使用动机会重新排序，H2和H5应当出现可观察变化。
- **[Uncertain]** 现有材料不能估计正式港币化、限制港元接受或改变联系汇率的财政成本、银行迁移成本、资产重估和不同居民群体的损益。

## Historical path

- **[Verified]** 澳门元具有从1905—1906年纸币发行安排开始的制度历史，之后经历1980年发行机构建立、1989年政府收回发钞权和1995年第二家发钞代理行加入等制度重组（E048）。
- **[Verified]** 当前澳门元仍由法律确认、由本地金融管理机构维护，并在2024—2026年持续更新纸币系列（E040、E049）。
- **[Inferred]** 发行权、监管机构、代理银行、价格法规和账户系统一旦累积起来，澳门元的退出就不再只是更换纸钞，而会触及行政记账、合同、金融产品和组织分工；这为路径依赖提供了比“身份象征”更直接的制度解释。
- **[Verified]** 港元长期承担澳门的交易媒介和价值储藏功能，官方研究在2006年前后已记录这种双货币结构（E051）；2026年银行体系统计仍显示港元占有较大份额（E045）。
- **[Uncertain]** 现有历史材料不足以确定澳门元保留中政治身份认同、财政收益、货币政策选择和技术转换成本各自的权重，也没有连续居民态度调查。

## Competing explanation retained

1. **主解释：本地计价和公共治理功能。** 澳门元保留的核心不是阻止港币进入私人交易，而是为价格、工资、公共管理、发行权和金融监管提供本地统一单位；这是目前证据最直接支持的机制（E040、E041、E049）。
2. **共同解释：联系汇率降低双货币并存成本。** 储备支持和港元挂钩让澳门可以获得港元网络的便利，同时保留澳门元，不必承担正式港币化的制度转换成本（E042、E044、E046）。
3. **共同解释：行业和跨境网络分工。** 港元接受由游客、跨境消费者、香港金融网络和部分商户需求推动，澳门元则由本地价格和公共结算网络维持；这一解释方向成立，但行业比例仍待现场和交易数据验证（E042、E045、E047、E051）。
4. **支撑解释：历史路径依赖。** 长期存在的发钞、监管、代理银行、纸币和支付系统使澳门元退出具有组织和转换成本；历史连续性支持这一点，但尚不足以把身份认同写成主要因果变量（E048、E049）。
5. **不保留为主要解释：澳门元只是象征，或港元使用完全由游客造成。** 当前银行体系、现行发行和法律计价证据反驳前者；港元在存款、贷款和历史价值储藏中的存在又削弱后者，但居民家庭的实际行为仍需单独调查（E045、E049、E051、E053）。

## Confidence

**Medium**：证据足以支持“澳门以澳门元维持法定计价和公共金融制度，同时借助联系汇率、旅游跨境网络和多币种金融基础设施吸收港元”的多重机制。证据不足以量化各行业的港币使用率、确认居民储蓄和投资货币，也不足以判断历史身份认同与技术转换成本谁更重要。

## One-sentence mechanism

澳门元持续存在，不是因为港币不能使用，而是因为本地法律、价格、工资、发行和金融监管需要澳门元作为制度记账单位；联系汇率和储备覆盖又降低了港币并存的兑换成本，使旅游、跨境和金融网络可以使用港币而不必正式港币化，最终形成由制度、市场网络和历史路径共同维持的双货币安排。
