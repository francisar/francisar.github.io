# Mechanism Map — HK-CROSSBORDER-001

## Observed scene

- **[Observed]** 2026年8月20日，在机场看到一辆同时出现香港牌和广东牌的车辆，并将其识别为“两地牌车”。
- **[Observed]** 车辆位于机场这一跨境人员和交通流动集中的场景。
- **[Uncertain]** 未记录车辆属于传统常规配额、港车北上、粤车南下还是其他跨境车辆类别。
- **[Uncertain]** 未记录车辆方向盘位置，因此不能从本次观察确认左舵或右舵。

## Immediate constraint

- **[Verified]** 香港与内地在道路行驶方向、车辆标准和驾驶环境上存在制度差异；香港道路采用左侧通行，内地道路采用右侧通行。
- **[Verified]** 跨境车辆不能只依靠一块车牌自然获得通行权，而要面对车辆登记、批准通知书、封闭道路通行许可证、驾驶人资格、保险、检验和口岸查验等接口要求。
- **[Inferred]** 对跨境运输主体而言，核心约束不是“能否买到一辆车”，而是能否使车辆、驾驶人、保险和通行路线同时满足两个制度的准入条件。

## Rule / institution

- **[Verified]** 传统粤港跨境车辆制度把广东批准通知书、香港封闭道路通行许可证、香港车辆牌照和内地驾驶证连接起来；主驾驶人还会与批准通知书和内地交通违法处理系统关联。
- **[Verified]** 港车北上、粤车南下等后续指定方案具有独立的车辆、驾驶人、保险、检验和预约要求，不能与传统常规配额制度简单合并。
- **[Verified]** 粤车南下要求指定驾驶人同时持有内地机动车驾驶证和香港正式驾驶执照；拥有广东—香港常规配额的车辆不能申请该方案。
- **[Verified]** 香港通常限制左舵车辆，但对部分跨境公务、企业和特殊用途车辆保留例外许可。

## Incentive effect

- **[Inferred]** 如果车辆和驾驶人能够直接跨境，运营主体可以减少换车、转运、等待和重新组织司机的需要；这构成承担配额、许可证、保险、检验和合规成本的经济激励。
- **[Inferred]** 对机场接送、商务出行和时间敏感运输而言，直接通行的时间价值可能高于复杂准入制度的固定成本。
- **[Uncertain]** 本次观察车辆是否确实因机场接送或商务运输而获得双地通行资格，尚无车辆用途和运营者证据。

## Behavioral response

- **[Inferred]** 能够持续跨境运营的企业会把车辆、指定驾驶人、保险和通行文件组织成一个合规组合，并沿获批口岸和路线重复运行。
- **[Verified]** 官方资料显示不同方案存在配额、指定驾驶人、车辆检验、保险和预约等要求，说明这不是普通车辆的临时穿越，而是被制度化筛选的运营行为。
- **[Verified]** 港珠澳大桥香港口岸的私家车通行量在2024—2025年增长，说明相关跨境车辆通行具有较大规模；但统计未单独识别传统两地牌车辆。

## Enforcement / feedback

- **[Verified]** 广东交通管理部门将两地牌车辆的主驾驶人与批准通知书、内地驾驶证及交通违法处理关联。
- **[Verified]** 粤车南下等方案要求联合审核、车辆检验、许可证、保险和预约，形成政府部门之间的前置筛选。
- **[Inferred]** 配额、文件匹配和口岸查验会把不符合条件的车辆和临时驾驶人排除在稳定跨境运营之外，并使合规车辆形成可重复识别的类别。
- **[Uncertain]** 本次观察中的车辆是否接受过何种查验、是否有电子备案、是否属于机场停车转乘服务，均未观察到。

## Organization / operator

- **[Verified]** 该机制涉及香港运输署、广东公安交通管理部门、海关、口岸及相关保险、检验和运营机构，而不是单一交通部门独立决定。
- **[Verified]** 机场相关的粤车南下停车转乘安排在2026年夏季扩展，机场因此可能成为新方案车辆集中出现的观察点。
- **[Inferred]** 机场运营方、接送企业、物流企业和跨境乘客共同把抽象的牌照制度转化为可见的车辆流和接驳服务。

## Distribution

- **Who gains / 谁受益：**
  - **[Inferred]** 获得资格的企业和车主可以减少跨境换车和转运摩擦。
  - **[Inferred]** 乘客、货主和机场接驳服务可能获得更连续的点到点运输。
  - **[Verified]** 有关方案存在资格、配额和指定驾驶人限制，因此收益并不向所有车辆和司机开放。
- **Who pays / 谁付费：**
  - **[Verified]** 运营主体需要承担许可证、保险、车辆检验、司机资格和通关合规成本。
  - **[Uncertain]** 本次车辆的具体费用、车主类型和运营收益没有记录。
- **Who bears risk / 谁承担风险：**
  - **[Inferred]** 驾驶人和企业承担证件不匹配、违法、事故、延误和车辆被扣留的直接风险。
  - **[Inferred]** 乘客、货主和保险人承担跨境责任认定不一致或服务中断的间接风险。
- **Who is excluded / 谁被排除：**
  - **[Verified]** 不符合车辆、企业、驾驶人、保险和配额条件的普通车主或临时司机无法直接获得同等通行资格。

## Historical path

- **[Verified]** 香港官方记录将粤港共同配额管理的一个明确里程碑追溯到1982年；广东官方后续行政记录还列出1984年、1988年和1992年的相关车辆及驾驶人管理文件。
- **[Verified]** 2012年出现跨境私家车一次性临时配额试验，2017年港珠澳大桥通车前相关私家车配额因需求踊跃由3,000增加至10,000。
- **[Verified]** 2023年港车北上、2025年底粤车南下以及2026年夏季扩容，显示跨境车辆制度并非一次形成，而是随着口岸、车辆类型和出行需求不断增加新的制度接口。
- **[Inferred]** 左舵与右舵并存更可能是两地既有道路和车辆标准叠加跨境例外许可的历史结果，而不是“双牌”本身主动制造了两种方向盘标准。
- **[Uncertain]** 目前证据没有确定“第一辆两地牌车”或传统双牌制度的唯一创设年份；1982年是配额管理里程碑，不应直接写成最早出现年份。

## Competing explanation retained

- **H1 — 行政协调先行：** 对“车辆、驾驶人和许可证如何衔接”解释力最高；对“最早何时出现”仍需查找1984、1988、1992年原始文件。
- **H2 — 需求倒逼：** 2012年交流频繁、2017年需求旺盛和跨境车辆增长提供支持，但现有材料不足以证明需求先于最初制度出现。
- **H3 — 基础设施先行：** 对港珠澳大桥开通后的配额扩容和机场可见度解释力较强，对传统制度起源解释力较弱。
- **H4 — 历史车辆标准遗留：** 对左舵/右舵并存提供了较合理的结构解释，但缺少传统两地牌车队方向盘构成的统计和准入细则。
- **H5 — 机场可见度效应：** 2026年夏季粤车南下扩容和机场停车转乘安排使其具有时间上的相关性，但不能据此认定观察车辆属于粤车南下。

## Failure mode and rule removal

- **[Inferred]** 如果两地牌或指定跨境许可消失，车辆可能需要在边界换车、转运货物、改用公共交通或退出部分跨境市场。
- **[Inferred]** 成本不会消失，而会转移到乘客、货主、企业和口岸交通组织；机场接送可能变得更慢、更碎片化。
- **[Uncertain]** 具体替代方式取决于车辆类型、口岸路线、运输时效和是否存在铁路或本地接驳替代方案。

## Confidence

**Medium**：现有材料足以支持“跨境车辆是由多部门许可、车辆登记、驾驶人资格、保险、检验和口岸查验共同组织的制度化通行”这一机制；但不足以确认观察车辆的具体方案、方向盘位置，或传统两地牌制度的唯一起源年份。

## One-sentence mechanism

跨境两地牌车不是单纯的车牌现象，而是香港与广东两套道路、车辆登记和驾驶人制度在跨境需求及口岸基础设施条件下，通过配额、批准通知书、通行许可证、保险、检验和查验接口组织出的重复性通行；2026年机场所见车辆可能因粤车南下新方案扩容而更易被看见，但其具体制度身份仍待现场证据核验。
