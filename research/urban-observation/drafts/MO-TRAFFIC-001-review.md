# Review — MO-TRAFFIC-001

## Scope

本次审阅针对 `research/urban-observation/drafts/MO-TRAFFIC-001-draft-v1.md`，检查它是否满足研究型城市观察记的街道、制度、因果、证据、政治经济和叙事要求。审阅保留“观察到多数车辆让行”这一现场描述，但不把它扩展为澳门整体交通行为的统计结论。

## Test results

### Street Test — PASS WITH SOFTENING

文章从无明显交通灯的人行横道和车辆减速、停车让行开始，清楚保留了观察者没有记录具体道路、时段和样本数量的限制。标题和个别句子仍把“没有红绿灯”写得略为绝对，修订版改为“看不见红绿灯的斑马线”或“未观察到明显信号控制”。

### Institution Test — PASS

文章识别了第37条让行规则、第103条罚则、道路标线和减速设施、治安警察局宣传与执法、交通监控服务及道路工程部门。公共视频监视、实时路况和具体人行横道之间没有被直接连接，修订版将这种关系明确写成治理能力和可能的反馈渠道，而不是现场事实。

### Causality Test — PASS

文章保留了规则、道路几何、即时互动、职业司机和不可见监督五种解释，并用2025年斑马线不让先处罚记录反驳“所有司机都会自动守规”的强版本。H4因缺少车辆类型、车队培训和本地组织数据，不再作为主要解释；H3保留为次级、待验证机制。修订版增加“如果删除标线、规则或监督反馈会怎样”的反事实边界。

### Evidence Test — PASS WITH OPEN GAPS

主要断言均回链到澳门证据台账的`E024`—`E038`，法规、道路设计、执法和统计资料的材料类别已经区分。仍需注意：官方存在监控服务不等于观察点被覆盖，619宗处罚不等于违法率，跨地区学术研究也不能替代澳门现场行为数据。修订版将“Verified”证据状态改为“Documented”，避免把文件存在误写成现场行为已经核实。

### Political Economy Test — PASS WITH INFERENCE LABELS

文章回答了谁决定、谁付费、谁受益、谁承担风险和谁被排除。公共设施成本、司机时间成本和行人注意力负担主要是基于制度设计的推论，不是成本调查结果；修订版保留“可能”“从制度设计看”等限定语。行人承担的身体风险及不同道路条件下的差异仍需要事故、速度和道路几何数据。

### Narrative Test — PASS FOR RESEARCH DRAFT

文章完成了“场景—异常—问题—调查—机制—历史—分配—回到街头”的路径，末尾重新回到斑马线并提出下一次观察应记录的变量。它仍是研究草稿，不是可以不经事实核对直接发布的成稿。

## Blocking issues

无阻断性问题。文章已经能够作为研究型观察记保存，但不应把单次观察写成澳门整体交通秩序的代表性结论。

## Non-blocking issues fixed in draft-v2

- 将标题和开头的“没有红绿灯”降格为“看不见红绿灯”或“未观察到明显信号控制”。
- 将公共监控资料与观察点之间的关系明确为可能的治理能力，不写成现场存在专用摄像头的证明。
- 将“监控、事故调查、投诉和事后追责”拆分为可检验的反馈渠道，避免单一来源支撑过多具体断言。
- 将“Verified”证据状态改为“Documented”，保留法规和统计事实与现场行为之间的距离。
- 增加删除标线、让行规则或监督反馈后的失效情景，同时说明无法量化让行率变化。
- 将职业司机和车队组织降为未获本地证据支持的解释，不再把它放进主机制。
- 明确不进行缺少同口径数据支撑的城市比较。
- 将正文从“Article Spec＋八个编号小节”改为四个较大的叙事段落，删除正文中的研究清单和重复性元信息。

## Evidence still missing

1. 观察点的具体道路、路口、时间、天气、交通流量和连续视频。
2. 每辆车在行人靠近、踏入和通过横道三个阶段的速度、停车距离和让行结果。
3. 标线、照明、视距、道路宽度、车道数量、限速、安全岛和减速设施的现场编码。
4. 观察点摄像头、巡逻、投诉或事故记录的覆盖与实际用途。
5. 出租车、公交、旅游巴士和私家车的行为差异，以及司机对规则和处罚的理解。
6. 以车辆和行人暴露量为分母的让行率、未让行率和事故风险数据。

## Final verdict

**PASS（研究草稿阶段）**：`MO-TRAFFIC-001-draft-v2.md` 已完成必要的措辞降格、证据边界和反事实补充，可以进入人工事实核对与文章润色；不建议在补充地点、样本和行为数据前直接发布到 `source/_drafts/`。
