# Review — HK-CROSSBORDER-001

## Scope

本次审阅针对 `research/urban-observation/drafts/draft-v1.md`，检查其是否适合作为研究型观察记初稿。审阅不把官方规定等同于实际合规行为，也不把机场现场观察扩展成对全部“两地牌车”的统计判断。

## Test results

### Street Test — PASS

文章从2026年8月20日机场看到的一辆双牌车辆开始，明确说明了没有记录车型、车牌位置、许可证和方向盘位置。现场事实与后续解释基本分开。

### Institution Test — PASS WITH SOFTENING

文章识别了车辆登记、批准通知书、封闭道路通行许可证、驾驶人资格、保险、检验、口岸和联合审核等制度接口，也涉及香港运输署、广东交通管理部门、海关和口岸机构。部分“对政府而言”“形成重复性运输”等句子需要明确标为推论，不能写成文件直接证明的事实。

### Causality Test — PASS

文章保留了行政协调、需求倒逼、基础设施先行、历史车辆标准和机场可见度五种解释，并设置了证伪方向。H1对“制度接口存在”的解释力最高，但对“最早出现年份”仍不充分；H5只能解释机场可见度，不能证明车辆身份。

### Evidence Test — PASS WITH OPEN GAPS

主要断言都回链到`E001`—`E023`。历史时间线仍依赖广东政府2000年的官方二手记录，1984年、1988年和1992年原始文件尚未取得；传统两地牌车辆的方向盘构成、车辆类型和真实合规行为也没有直接证据。

### Political Economy Test — PASS WITH INFERENCE LABELS

文章回答了谁受益、谁付费、谁承担风险和谁被排除。由于缺少企业成本、司机访谈和事故/保险资料，相关内容应使用“可能”“从制度设计看”或`[Inferred]`，不能写成已观察到的结果。

### Narrative Test — PASS FOR RESEARCH DRAFT

结构完成了“现场—异常—问题—机制—历史—分配—比较—回到现场”的顺序。当前文件仍是文章规格和叙事草稿，不是可直接发布的完整散文；比较部分应明确为后续取证设计，而不是已经完成的城市比较。

## Blocking issues

无阻塞性问题。观察事实、证据事实和推论已能在研究草稿中共存。

## Non-blocking issues fixed in draft-v2

- 将“收益并不是平均分配”“愿意承担成本”等确定语气改为制度推论语气。
- 将“机场是跨境流动集中的场景”改为“机场可能提高相关车辆的可见度”。
- 将2012年需求与制度出现之间的关系改为待检验的时间顺序问题。
- 将2026年粤车南下扩容与机场观察的关系明确为时间相关性，而非因果证明。
- 将香港机场与珠海口岸的内容改为比较设计，避免声称已经完成同口径比较。
- 将“Verified”证据状态改为“Documented evidence”，避免把文件存在误写成现场行为已经核实。

## Evidence still missing

1. 1984年广东省公安厅暂行规定、1988年国务院办公厅复函和1992年广东省政府通知的原始文本。
2. 观察车辆的机场、停车区、车型、车牌位置、车辆用途和许可证类别。
3. 传统常规配额车辆关于左舵、右舵、灯光、后视镜、改装和检验的准入细则。
4. 不同方案的实际车牌/许可证外观，以及司机、保险人和运营企业对证件链条的说明。
5. 区分两地牌车的机场和口岸分项流量，而不是使用全部私家车流量替代。

## Final verdict

**PASS（研究草稿阶段）**：`draft-v2.md` 已完成必要的降格和边界标注，可以进入人工事实核对和文章润色；仍不建议直接发布到`source/_drafts/`，直到观察车辆身份和历史原始文件得到进一步核验。
