# Review — MO-CURRENCY-001

## Scope

本次审阅针对 `research/urban-observation/drafts/MO-CURRENCY-001-draft-v1.md`，检查它是否满足研究型城市观察记的街道、制度、因果、证据、政治经济和叙事要求。审阅保留“港币广泛使用、澳门元仍然保留”这一现场观察，但不把它扩展为澳门居民或全澳门商户的行为统计。

## Test results

### Street Test — PASS WITH SOFTENING

文章从澳门街头两种货币并存的印象开始，也明确说明没有记录具体商户、街区、价格牌、找零和观察日期。现场锚点成立，但“澳门的地方并不大”和“港币可以在不少日常场景中使用”仍然略显宽泛；修订版将其写成观察者的空间感受和待量化判断，并说明本文只追踪澳门元—港币这一对货币，不把澳门多币种体系穷尽。

### Institution Test — PASS WITH SOFTENING

文章识别了澳门元的法定货币地位、价格和工资计价、电子支付、货币发行局、外汇储备、发钞代理行、银行、旅游部门和商户等制度接口。主要问题是部分段落在同一段中同时放入法规事实和“因此会怎样”的推论；修订版把法律和统计事实与行为、激励和分配推论拆开标记。

### Causality Test — PASS WITH SOFTENING

文章保留了本地公共计价、联系汇率、行业网络、历史路径和居民组合使用五种解释，并拒绝“澳门元只是象征”及“港币完全由游客造成”的强版本。结论方向合理，但“澳门没有直接港币化，并不是因为港币不能使用”语气过于排他；现有证据只能说不支持把澳门元保留解释为港币不能使用，修订版改为更可证伪的表述。

### Evidence Test — PASS WITH OPEN GAPS

法规、旅游资料、消费者调查、2026年6月金融统计、2026年7月外汇储备、历史年鉴、纸币发行和证券投资调查均回链到 `E040`—`E053`。当前数据已有明确时点，但仍需注意：2019年前后商户调查于2020年发布，不能代表2026年；M2、存款和贷款是银行体系总体口径；证券投资统计包括政府及其他法人且没有投资币种。修订版进一步把这些日期和口径放回正文。

### Political Economy Test — PASS WITH INFERENCE LABELS

文章回答了谁获得支付便利、谁维护制度接口、谁承担兑换和现金管理成本、谁承担双重报价的信息成本以及澳门对港元金融网络的依赖。相关成本、收益和风险没有直接调查支撑，现稿已经大体使用推论标记；修订版会避免将“居民可以如何选择”写成居民已经如此选择。

### Narrative Test — PASS

正文只有五个小节，完成了“街头场景—货币异常—制度机制—历史与分配—回到街头”的路径，没有重复拆成过多子章节。结尾把下一次观察应记录的价格单位、报价汇率、找零和支付方式重新带回街头，符合观察记要求。

## Blocking issues

无阻塞性问题。初稿已经具备研究型文章的完整主线；需要的是措辞降格、状态拆分和时点提示，而不是改变核心机制。

## Non-blocking issues fixed in draft-v2

- 将“澳门的地方并不大”改成观察者的空间尺度感受，避免未经指标支撑的规模判断。
- 明确本文聚焦澳门元与港币，不把人民币及其他支付工具排除在澳门整体货币环境之外。
- 将法规、官方统计和历史事实与“因此会形成什么行为”的推论拆成不同状态标签。
- 将“澳门没有直接港币化，并不是因为港币不能使用”改为不排他的证据结论。
- 在正文中标出2019年前后调查、2020年发布、2025年末投资统计、2026年6月金融统计和2026年7月储备统计的时点。
- 删除或软化“完全陌生、剧烈波动”等缺乏直接证据的措辞。
- 保留居民货币组合为待验证假设，不把银行总体数据和境外证券投资数据写成普通居民的直接行为证明。

## Evidence still missing

1. 观察地点、商户类型、交易金额、观察日期、价格牌、实际报价汇率和找零货币。
2. 按旅游、博彩、酒店、交通、社区零售和公共服务拆分的港币接受率与结算规则。
3. 银行、ATM、银行卡和移动支付中澳门元、港币及人民币的实际使用路径和费用。
4. 按居民、跨境劳动者、游客、企业和收入群体区分的现金、存款、贷款、工资及投资货币数据。
5. 公共收费、政府工资、租金、贷款和合同的实际计价货币，以及第16/95/M号法令现行适用范围的逐项核验。
6. 商户实际汇率价差、找零成本、消费者投诉和双货币使用对不同群体的影响。

## Final verdict

**PASS（研究草稿阶段）**：`MO-CURRENCY-001-draft-v2.md` 已完成必要的现场边界、证据时点、状态标记和竞争性解释修订，可以进入人工事实核对与文章润色；在补充商户交易数据和居民家庭金融数据前，不建议直接发布到 `source/_drafts/`。
