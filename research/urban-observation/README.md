# 城市观察研究记录

这是城市观察 skill 的产出目录。它与金融研究并行，但可以在城市经济、住房、交通、公共服务、消费和产业空间等主题上交叉引用。

## 产出链路

```text
现场材料
  ↓ /observe
observations/<city>/
  ↓ /question -> /hypothesize
synthesis/
  ↓ /research
evidence/evidence-ledger.csv
  ↓ /synthesize
synthesis/*-mechanism.md
  ↓ /write -> /review
drafts/
  ↓ 人工确认后
source/_drafts/
```

## 状态约定

- `observed`：来自现场材料的可见事实。
- `verified`：已由可靠来源核验的事实。
- `inferred`：基于证据形成的推断。
- `uncertain`：当前证据不足或存在冲突。

不要把观察记录直接改写成宏大结论。重要结论必须能回到观察、证据、机制和分配结果。
