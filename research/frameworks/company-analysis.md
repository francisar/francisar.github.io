# 上市公司分析框架

## 1. 公司身份与研究问题

- 公司提供什么产品或服务，客户为什么购买？
- 收入按产品、地区、客户和渠道如何拆分？
- 公司处于扩张、成熟、转型、困境还是清算阶段？
- 本次研究要解决哪个具体问题？

## 2. 商业模式与单位经济学

- 用户获取、转化、留存、复购和变现如何发生？
- 单位收入带来的毛利、履约成本、销售费用和服务成本是多少？
- 增长需要新增多少销售、产能、库存、资本开支或营运资金？
- 客户集中度、合同期限、续约率和议价权如何？

## 3. 行业位置与竞争优势

分析规模、成本、品牌、渠道、网络效应、数据、牌照、供应链和转换成本。每个优势都要回答：

- 优势来自什么具体机制？
- 竞争者复制需要多久、多少钱或什么资源？
- 优势能否带来更高价格、更低成本、更高留存或更少资本投入？
- 过去三到五年是否有证据证明优势仍然存在？

## 4. 财务表现与增长质量

至少整理五年的收入、毛利、经营利润、净利润、经营现金流、自由现金流、资本开支、净负债和股本变化。重点拆解：

- 增长是销量、价格、并购、汇率还是会计口径变化？
- 利润率变化是规模效应、产品组合、成本周期还是一次性项目？
- 现金流是否支持利润，营运资本是否吞噬增长？
- 资本开支和研发投入是否带来可验证的回报？

## 5. 资本配置与治理

- 管理层把现金用于扩产、研发、并购、分红、回购还是偿债？
- 并购价格、商誉和整合结果如何？
- 管理层是否有清晰的股东回报和风险控制记录？
- 关联交易、股权激励、担保、质押、审计意见和控制权结构是否存在风险？

## 6. 估值与情景

同时记录当前价格或估值口径、可比公司、历史区间和现金流估值。建立情景表：

| 情景 | 收入 | 利润率 | 资本开支 | 主要依据 | 触发条件 |
| --- | --- | --- | --- | --- | --- |
| 悲观 |  |  |  |  |  |
| 基准 |  |  |  |  |  |
| 乐观 |  |  |  |  |  |

不要把目标价当作结论。结论应描述市场价格隐含了什么假设，以及这些假设是否有足够证据支持。

## 7. 风险与反证

分别记录业务风险、财务风险、治理风险、监管风险、竞争风险、估值风险和流动性风险。每项风险写出概率、影响、可观测指标和应对方式。

## 8. 投资研究结论

用一页回答：

1. 公司最重要的价值创造机制是什么？
2. 当前最强和最弱的证据分别是什么？
3. 未来一到三年最重要的变量是什么？
4. 什么事实会推翻当前判断？
5. 下一次应该查阅哪些数据或公告？

## 9. 更新日志

每次更新记录日期、事件、原判断、最新证据、判断变化和未解决问题。这样可以区分当时不知道什么，而不是事后用结果重写历史。
