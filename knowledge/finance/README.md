# 金融基础知识体系

这里沉淀跨行业、跨公司的金融基础知识。知识条目应该尽量稳定、可复用，并与具体公司的观点分开保存。

## 学习地图

| 模块 | 要回答的问题 | 建议产出 |
| --- | --- | --- |
| 会计与财报 | 公司如何确认收入、利润和现金流？ | 三张表拆解、会计政策笔记、财务质量清单 |
| 经济与市场 | 利率、通胀、周期和流动性如何影响资产？ | 宏观变量卡片、周期观察记录 |
| 企业与行业 | 公司为谁创造价值，行业如何分配利润？ | 价值链、竞争格局、商业模式卡片 |
| 估值 | 未来现金流或资产应当如何定价？ | DCF、相对估值、情景估值 |
| 风险与组合 | 哪些因素会导致永久性损失？ | 风险清单、仓位与退出条件 |
| 治理与行为 | 管理层如何使用资本，投资者如何犯错？ | 治理检查表、行为偏差复盘 |

## 推荐顺序

1. 先掌握资产负债表、利润表和现金流量表之间的勾稽关系。
2. 再理解收入、利润、现金流、资本开支和营运资本的经济含义。
3. 用价值链和单位经济学解释公司，而不是先看估值倍数。
4. 用多种估值方法建立区间和敏感性，而不是追求单一目标价。
5. 最后写明假设、证据、反证条件和可能的永久性损失。

## 知识条目格式

每个知识条目建议包含：

- **定义**：用自己的话解释概念。
- **直觉**：说明它为什么重要。
- **公式或机制**：只保留能帮助判断的公式。
- **例子**：使用脱敏或公开数据说明。
- **边界**：说明什么时候会失效。
- **关联**：链接到行业、公司或研究记录。
