# 财务报表与财务质量

## 核心目标

读财报不是为了把所有科目背下来，而是回答四个问题：

1. 公司卖什么，收入是否真实、可持续？
2. 每增加一单位收入，能留下多少经营利润和现金？
3. 增长需要投入多少资本，回报是否超过资本成本？
4. 哪些会计判断可能让利润暂时看起来更好？

## 三张表的连接

### 资产负债表

基本关系是：

```text
资产 = 负债 + 股东权益
```

重点关注资产的流动性、负债的到期结构、商誉和无形资产占比、应收账款与存货变化，以及权益是否被持续亏损侵蚀。

### 利润表

利润表描述一段期间的经营结果。分析时要把收入增长拆成价格、销量、产品组合、并表范围和汇率等因素，再观察毛利率、费用率和经营利润率的变化。

### 现金流量表

现金流量表帮助判断利润是否转化为现金。经营现金流、资本开支、自由现金流和融资现金流应放在一起阅读，不能只看净利润。

## 连接关系

- 利润通过留存收益进入资产负债表。
- 折旧摊销减少利润，但通常不直接减少当期现金。
- 应收账款、存货和应付账款的变化会造成利润与经营现金流的差异。
- 资本开支通常先影响投资现金流，随后通过折旧影响利润。
- 借款、还本、分红和回购分别影响融资现金流与资产负债表。

## 常用指标

| 指标 | 公式 | 主要用途 |
| --- | --- | --- |
| 毛利率 | 毛利 / 收入 | 判断产品或服务的基础盈利空间 |
| 经营利润率 | 经营利润 / 收入 | 判断主营业务的经营杠杆 |
| ROIC | 税后经营利润 / 投入资本 | 判断增长是否创造价值 |
| 经营现金流转化率 | 经营现金流 / 净利润 | 判断利润的现金支持程度 |
| 自由现金流 | 经营现金流 - 资本开支 | 判断可分配或可再投资的现金 |
| 应收账款周转天数 | 平均应收账款 / 收入 × 期间天数 | 观察回款质量 |
| 存货周转天数 | 平均存货 / 销售成本 × 期间天数 | 观察库存效率和减值风险 |

## 财务质量检查

- 收入增长是否伴随应收账款、合同资产或渠道库存异常增长？
- 毛利率变化是价格、成本、产品组合还是会计口径变化造成的？
- 净利润增长是否依赖公允价值变动、补贴、处置收益或一次性项目？
- 经营现金流是否长期落后于净利润？
- 资本化开发支出、并购商誉或关联交易是否改变了利润表现？
- 短期借款、租赁负债、担保和表外承诺是否会造成流动性压力？

## 记录要求

每次使用财务数据时，记录报告期、币种、合并口径、数据来源和是否经过调整。调整后的指标必须同时保留原始指标和调整理由。
