# 估值方法与假设管理

## 估值的基本关系

估值是对未来现金流、资产或收益能力的条件性判断，不是对价格的确定性预测。每个估值结论都应明确：数据日期、预测期限、关键假设、敏感变量和失效条件。

## 现金流折现

基本流程：

1. 解释收入、利润率、税率、营运资本和资本开支的驱动因素。
2. 预测自由现金流，而不是直接把历史利润外推。
3. 选择与现金流风险相匹配的折现率。
4. 计算终值，并检查终值占企业价值的比例。
5. 对收入增长、利润率、折现率和终值增长率做敏感性分析。

常见自由现金流表达式：

```text
FCFF = 税后经营利润 + 折旧摊销 - 资本开支 - 营运资本增加
```

## 相对估值

市盈率、EV/EBITDA、EV/收入、EV/毛利率或自由现金流收益率都只是比较工具。使用倍数时，必须说明可比公司的增长、利润率、资本强度、周期位置和会计口径是否相近。

## 其他方法

- **分部估值**：适用于业务差异大、需要不同估值口径的公司。
- **资产估值**：适用于金融、资源、地产或资产价值是主要驱动因素的场景。
- **情景估值**：适用于商业模式、政策、技术路径或竞争格局存在较大不确定性的公司。
- **反向估值**：从当前价格反推市场隐含的增长、利润率或资本回报假设。

## 估值纪律

- 先理解业务，再选择估值方法。
- 优先使用区间、情景和敏感性，不输出脱离假设的单点结论。
- 把估值误差拆成业务判断误差、财务预测误差和市场定价误差。
- 对周期性公司使用正常化利润或跨周期现金流，而不是直接使用高点或低点数据。
- 对估值结果做反事实检查：什么条件下当前价格已经合理，什么条件下明显过于乐观？
